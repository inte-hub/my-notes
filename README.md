# my-notes
Interview prep notes for webMethods and enterprise integration.

## Repository index
This repository contains a set of study and interview preparation notes focused on webMethods development, B2B integration, SOAP/REST, messaging, and interview storytelling.

### Files
- `Study_Guide.md` — a structured study guide for the webMethods platform, integration concepts, REST/SOAP basics, messaging, and interview readiness.
- `Mock_interview.md` — a mock interview question set with strong answer guidance, follow-up probes, and senior-level talking points for webMethods developer interviews.
- `Project_Info.md` — a project story template and architecture narrative for a partner onboarding / B2B integration platform, written for interview-friendly storytelling.
- `webMethods_refresher.md` — a technical refresher covering key webMethods components, integration server concepts, trading networks, adapters, and architecture.

## How to use this repo
1. Read `Study_Guide.md` first to refresh foundation and platform knowledge.
2. Practice out loud with `Mock_interview.md` to build confidence on common questions and probes.
3. Use `Project_Info.md` to shape your own project story and match it to job description themes.
4. Consult `webMethods_refresher.md` for deeper technical details and platform architecture review.

## Goal
Keep this repo as a concise study reference for interview preparation and as a quick way to revisit core webMethods concepts and talking points.
